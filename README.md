🌿 Farmecho - Administração de Fazendas Urbanas 🚜


Farmecho é um software desenvolvido em C# utilizando .NET e Windows Forms, com o objetivo de centralizar a administração de fazendas urbanas em uma única plataforma. O sistema implementa operações CRUD (Create, Read, Update, Delete) integradas ao banco de dados Microsoft SQL Server (MSSQL) e segue o padrão de arquitetura MVC (Model-View-Controller).

🌾 Funcionalidades:


🌱 Gerenciamento de Culturas: Cadastro e monitoramento de diferentes tipos de plantas cultivadas.
📦 Controle de Estoque: Gestão de insumos e produtos disponíveis.
💰 Registro de Vendas: Acompanhamento das vendas realizadas e geração de relatórios.
📊 Relatórios Personalizados: Criação de relatórios detalhados sobre a produção e vendas.
🛠 Tecnologias Utilizadas
💻 Linguagem: C#
⚙️ Framework: .NET
🖥 Interface Gráfica: Windows Forms
🗄 Banco de Dados: Microsoft SQL Server (MSSQL)
🏗 Arquitetura: MVC (Model-View-Controller)

📌 Pré-requisitos:

🏗 .NET Framework: Versão 4.7.2 ou superior
🗃 SQL Server: SQL Server 2016 ou superior
🛠 Visual Studio: Versão 2019 ou superior

Após a instalação e execução, o Farmecho fornecerá uma interface amigável para gerenciar sua fazenda urbana. Utilize os menus para navegar entre as funcionalidades, como cadastro de culturas, controle de estoque e geração de relatórios.
